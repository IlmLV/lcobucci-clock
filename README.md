# Clock

This fork is created from [lcobucci](https://github.com/lcobucci)/[clock](https://github.com/lcobucci/clock) v3.0.0 with as little changes as possible for PHP v8.1 and v8.3 compatibility.

It is created for chance to upgrade from php versions skipping PHP v8.2 upgrade iteration.

Use it on your own risk.

## Usage

Install: `composer require ilmlv/lcobucci-clock:3.0.1`

After upgrading PHP to 8.3 no need to keep using this package, it will not be updated.
Remove it `composer remove ilmlv/lcobucci-clock` and if neccessary replace by original package requirement `composer require lcobucci/clock`
